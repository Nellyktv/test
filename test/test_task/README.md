## О проекте

Это простое мини-приложение магазина на React с TypeScript, где можно:

- Просматривать каталог товаров
- Фильтровать и искать товары
- Добавлять товары в корзину
- Управлять количеством товаров в корзине
- Сохранять корзину в `localStorage`
- Переключаться между страницами каталога

Приложение использует axios для работы с FakeStore API и React Router для навигации между страницами.

---

## Стек технологий

- React (функциональные компоненты, хуки)
- TypeScript
- React Router Dom 
- CSS Modules
- Axios
- LocalStorage для корзины
